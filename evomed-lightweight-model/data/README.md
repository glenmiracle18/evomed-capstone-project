# Data Directory

## Large Data Files Not Included in Repository

Due to GitHub file size limits, the following large data files are not included in this repository:

### Required Data Files

1. **variants(1).tsv** (296 MB)
   - Source: BRCA Exchange
   - URL: https://brcaexchange.org/releases
   - Description: Complete BRCA1 variant dataset with clinical annotations
   - Location: Place in `evomed-lightweight-model/data/`

2. **Preprocessed Training Data** (Generated)
   - `processed/train.csv` - Training set (8,205 variants)
   - `processed/val.csv` - Validation set (1,026 variants)
   - `processed/test.csv` - Test set (1,026 variants)
   - Generated by: `python scripts/prepare_training_data.py`

3. **Trained Model** (Generated)
   - `results/random_forest_model.joblib` (4.9 MB)
   - Generated by: `python training/train_random_forest.py`

## How to Set Up Data

### Step 1: Download BRCA Exchange Data

```bash
# Download from BRCA Exchange
wget https://brcaexchange.org/backend/downloads/releases/release-12-10-23/variants.tsv

# Or visit https://brcaexchange.org/releases and download manually

# Rename and move to data directory
mv variants.tsv evomed-lightweight-model/data/variants(1).tsv
```

### Step 2: Prepare Training Data

```bash
cd evomed-lightweight-model
python scripts/prepare_training_data.py
```

This will create:
- `data/processed/train.csv` (8,205 variants)
- `data/processed/val.csv` (1,026 variants)
- `data/processed/test.csv` (1,026 variants)
- `data/processed/metadata.json`

### Step 3: Train Model (Optional)

```bash
# Train locally
python training/train_random_forest.py

# Or train on Modal cloud
modal run training/train_random_forest_modal.py
```

## Data Statistics

- **Total Variants**: 36,726 BRCA1 variants
- **Labeled Variants**: 10,257 with clear pathogenicity
- **Training Set**: 8,205 variants (80%)
- **Validation Set**: 1,026 variants (10%)
- **Test Set**: 1,026 variants (10%)
- **Class Distribution**: 60.6% Benign, 39.4% Pathogenic

## Alternative: Use Pre-trained Model

If you only want to run inference without training:

```bash
# Download pre-trained model from Modal volume (if available)
modal volume get evomed-rf-results random_forest_model.joblib results/

# Or train the model yourself (takes <2 seconds)
python training/train_random_forest.py
```
